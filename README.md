# MedSim 2.0 — Hospital Simulator

Versi 2.0 dari MedSim dengan sistem case yang bisa dibuat dan dikelola langsung dari browser.

## Fitur
- 🩺 Interactive Hospital Simulator
- ➕ Case Builder — buat kasus sendiri tanpa edit kode
- 📚 Case Library
- ✏️ Edit Case
- 🗑️ Delete Case
- 🎲 Random Case
- 💾 localStorage — data case tersimpan di browser
- 🧪 Custom examinations & results
- 🧠 Custom diagnosis + jawaban benar
- 📱 Responsive

## Deploy ke GitHub Pages
Upload `index.html`, `style.css`, `script.js`, dan `README.md` ke repository GitHub. Lalu:
**Settings → Pages → Deploy from a branch → main → /root → Save**

## Catatan
Aplikasi ini adalah simulasi edukasi. Data dan hasil kasus tidak dimaksudkan untuk diagnosis atau keputusan medis nyata.
